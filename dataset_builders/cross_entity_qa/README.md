# Cross-Entity QA Dataset Generation

A pipeline for generating cross-entity question-answering datasets with variable K (number of relevant passages per query) for evaluating RAG retrieval systems.

## Overview

This project generates QA datasets where each query requires retrieving K passages (where K varies from 2-20) to fully answer. The dataset is designed to evaluate retrieval systems that need to find multiple related passages about different entities.

### Key Features

- **Variable K**: Queries require 2-20 relevant passages each
- **Entity Clusters**: Entities grouped by relationships (movie casts, award winners, etc.)
- **Constraint-Based Queries**: Temporal/categorical constraints ensure precise K values
- **Difficulty Levels**: 90% easy, 7% medium, 3% hard queries
- **Quality Filtering**: Multi-stage filtering for high-quality queries

## Full Pipeline

The complete pipeline has three phases:

### Phase A: Data Preparation

#### A.3: Enumerate Entity Clusters

Query Wikidata for entity clusters (award winners, movie casts, etc.):

```bash
python entity_enumerator.py --output data/clusters
```

This creates cluster files like:

- `award_Q38104_2010_2023.json` - Nobel Physics winners 2010-2023
- `cast_Q25188.json` - Cast of Inception
- `filmography_Q8877.json` - Films by Steven Spielberg

Each cluster contains entities with metadata (QID, label, description, year properties).

#### A.4: Map Wikipedia Passages

Extract Wikipedia passages for all entities in clusters:

```bash
python map_all_passages.py --clusters data/clusters --output data/passages
```

This creates passage files with extracted Wikipedia content for each entity.

**Output:**

- `data/passages/{cluster_id}_passages.json` - Passages for each cluster
- `data/passages/mapping_summary.json` - Summary statistics

### Phase B/C: Query Generation

Generate the QA dataset from prepared clusters and passages:

```bash
# Test mode (recommended first)
python generate_dataset.py --test --queries 12

# Full generation with OpenAI
python generate_dataset.py --provider openai

# Full generation with Anthropic Claude
python generate_dataset.py --provider anthropic

# Custom settings
python generate_dataset.py --provider openai --target 240 --output my_dataset
```

## Command Reference

### entity_enumerator.py

Enumerate entity clusters from Wikidata.

```bash
python entity_enumerator.py [OPTIONS]
```

| Option     | Description                   | Default       |
| ---------- | ----------------------------- | ------------- |
| `--output` | Output directory for clusters | data/clusters |
| `--types`  | Cluster types to enumerate    | all           |

### map_all_passages.py

Map Wikipedia passages for cluster entities.

```bash
python map_all_passages.py [OPTIONS]
```

| Option       | Description                   | Default       |
| ------------ | ----------------------------- | ------------- |
| `--clusters` | Directory with cluster files  | data/clusters |
| `--output`   | Output directory for passages | data/passages |

### generate_dataset.py

Generate the QA dataset.

```bash
python generate_dataset.py [OPTIONS]
```

| Option        | Description                       | Default          |
| ------------- | --------------------------------- | ---------------- |
| `--test`      | Run in test mode (small scale)    | False            |
| `--queries N` | Number of queries in test mode    | 6                |
| `--provider`  | LLM provider: openai or anthropic | openai           |
| `--model`     | Model name                        | Provider default |
| `--target N`  | Target number of queries          | 240              |
| `--sparsity`  | Target corpus sparsity            | 0.02 (2%)        |
| `--data-dir`  | Input data directory              | data             |
| `--output`    | Output directory                  | output           |
| `--export-corpus` | Export all passages (no LLM needed) | False        |

**Examples:**

```bash
# Export all passages for RAG indexing (no API key needed)
python generate_dataset.py --export-corpus

# Test mode with 10 queries
python generate_dataset.py --test --queries 10

# Full generation with GPT-4o-mini
python generate_dataset.py --provider openai --model gpt-4o-mini

# Generate 100 queries with Claude
python generate_dataset.py --provider anthropic --target 100
```

## Pipeline Stages

### Stage 1: Data Loading

- Loads enumerated clusters from `data/clusters/`
- Loads mapped passages from `data/passages/`
- Filters clusters with valid passages

### Stage 2: Constraint-Based Sub-Clustering

- Creates sub-clusters using temporal constraints (year ranges)
- Matches target K values through natural filtering
- E.g., "Nobel Physics 2010" = K=2, "Nobel Physics 2010-2015" = K=12

### Stage 3: Query Generation

- Uses LLM to generate natural language queries
- Queries include temporal/categorical constraints
- Applies difficulty levels (90% easy, 7% medium, 3% hard)

### Stage 4: Quality Filtering

- Validates query format and structure
- Filters by K-alignment and coverage
- Applies diversity filters

### Stage 5: Corpus Assembly

- Creates passage corpus with target 2% sparsity
- Adds hard negatives (semantically similar but not relevant)
- Adds random negatives

## Output Files

After running the full pipeline, the output directory contains:

```
output/CrossEntityQA/
├── corpus.jsonl           # All passages for RAG indexing
├── queries.jsonl          # All queries
├── qrels.tsv              # Relevance judgments (TREC format)
└── metadata.json          # Dataset statistics
```

### File Formats

**corpus.jsonl** (one JSON object per line):

```json
{
  "passage_id": "Q38111_p0",
  "text": "Leonardo DiCaprio is an American actor...",
  "entity_qid": "Q38111",
  "entity_label": "Leonardo DiCaprio"
}
```

**queries.jsonl** (one JSON object per line):

```json
{
  "query_id": "award_Q38104_easy_0",
  "query_text": "Who won the Nobel Prize in Physics in 2010?",
  "cluster_id": "award_Q38104_2010_2023",
  "difficulty": "easy",
  "target_k": 2,
  "temporal_constraint": "in 2010"
}
```

**qrels.tsv** (TREC format, tab-separated):

```
query_id    0    passage_id    relevance
award_Q38104_easy_0    0    Q104104_p0    1
award_Q38104_easy_0    0    Q106494_p0    1
```
